# 90-second walkthrough

1. Start the app and keep the default narrow family, seed 41, balanced policy.
2. Explain that every value is synthetic; no chemical sensing hardware is involved.
3. Click Acquire sample and read the reconstruction, observation lower third and actual sample ledger.
4. Use Play survey, then pause and drag the observation slider backward. Replay is deterministic; reduced motion uses manual replay only.
5. Inspect the four-policy table: identical ceilings can produce different actual sample counts.
6. Rotate the 3D surface. Its height shows posterior concentration, not ground elevation.
7. Reveal the evaluator map. Point out the narrow hotspot the posterior missed.
8. Download the complete JSON audit and inspect observations before each selection.
9. Open the research figure and explain why regular-grid hotspot recall exceeds balanced recall despite higher mean RMSE.

The running app is local; a GitHub repository alone would not host it.
